Brand Book / Toolkit
tkxel.com

Consistency, recognizability and resonance carry our visual story. Our aesthetic is technical and precise structured architecture, bold elements balanced against clean and minimal composition, generous negative space that lets the message hold the room.

The system reflects the work: applied AI, delivered by engineers who have shipped it. Deep expertise, an optimistic outlook, and a problem-solving instinct pointed at our clients' hardest questions.

The tkxel mark is the centerpiece. Around it sits a modular system, a defined set of components, colors and layouts that combine in an effectively unlimited number of ways, without ever producing something that looks unlike us.

Shape Names

Each shape within the tkxel system is intentionally named to reflect both its visual character and its conceptual role.

Names are short, expressive, and abstract, allowing shapes to be used across services, industries, and future offerings without becoming literal or restrictive. This naming approach supports longevity and flexibility, ensuring the system can evolve as tkxel grows.

Shape names act as a shared language between designers, marketers, and product teams, making the system easier to understand, reference, and apply consistently.

Typography

Every typeface in the system has exactly one job. Mixing them by habit rather than by role is the fastest way to make a document feel assembled instead of designed.

THE TWO TYPEFACES

  • Plus Jakarta SansEverything, content and interface alike — headings and body copy across every document and slide, plus navigation, buttons and the annotation/review layer. One sans typeface, used consistently everywhere.
  • IBM Plex MonoLabels, section numbers, data figures and kickers — small-caps, wide-tracked. The system's way of saying "this is metadata," everywhere it appears.

HOW TO USE THE FONT Plus Jakarta Sans font

For Digital Assets
Select font in typography and open settings
Open the Details panel
Turn off the ligatures value
For Web
CSS
.disable-ligatures{font-variant-ligatures: none;
font-feature-settings: "liga" 0, "clig" 0, "calt" 0;}
Disable the ligatures value

Imagery

These guidelines exist to hold consistency across every deliverable — so a White Paper cover and a LinkedIn post read as the same brand at a glance. Source stock images with a clean, unedited look no filters, no baked-in grading. We apply our own treatment, and a pre-graded image can't be brought back in line. Always choose images related to the topic.

RULES

Gradient overlay. Where type sits on an image, apply the brand gradient so contrast holds. Never set type on an untreated photograph.

Shapes with imagery. Crop a shape into one corner, or scale it across the full frame as a wash. Always the document's assigned shape.

Tags. Labeled pills to mark regions or features. Maximum three, placed clear of the subject.

Icons and logos. Reversed white version on photography. Check contrast against the area behind it, not the image overall.

One treatment per image. Four at once reads as none of them.

5.0

Iconography

One icon style, one grid, one source — icons read as a set even when they're pulled from different documents and pieced together on the same page.

PRINCIPLES

  • Source — Material Symbols plugin (Sharp style), not drawn from scratch
  • Weight — can vary with the heading size or text it sits beside
  • Grid — 24dp optical size, Fill off, Grade Normal, always
  • Color — black or a brand blue only, never filled
